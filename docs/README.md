## 🎯 核心决策摘要

- **技术栈**：HTML5 Canvas 2D + TypeScript + Vite（轻量零依赖，单人可控）
- **架构**：引擎层 → 场景层 → 实体层 → 服务层 → 数据层，五层解耦
- **存储**：LocalStorage（配置/进度）+ IndexedDB（排行榜）
- **玩法**：6 关卡 + 无尽模式，6 种敌机 + 6 个 BOSS，6 类道具，5 级武器
- **性能目标**：桌面 60FPS / 移动 30FPS+ / 内存 <100MB
